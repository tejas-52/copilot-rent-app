# RentReady AI (copilot-rent-app)

An AI copilot that helps renters prepare complete rental applications: onboarding, documents, an assistant, an application agent and a report.

## Tech stack

TanStack Start, React, TypeScript, Vercel AI SDK, Supabase, i18next

## Run locally

```sh
npm install
npm run dev
```

Set the Supabase values in `.env`.
